### Pass by Reference

- 메서드에 파라미터를 전달할 때, 만약 레퍼런스(참조)로 전달하고자 한다면 C# 키워드 ref를 사용한다.
- ref를 사용할 경우 메서드 내에서 변경된 값은 return 후에도 유효하다.
- ref 키워드는 메서드 정의와 메서드 호출 양쪽 모두에서 사용해야 한다.
- ref로 사용되는 변수는 무조건 사전에 초기화가 되어있어야 한다.

- ref와 비슷한 키워드로 out이 있다.
- out은 ref와 달리 메서드 내에서 반드시 값을 할당해야 하며, 메서드 호출 시 초기화되지 않은 변수를 사용할 수 있다.

### Named 파라미터 

- 메서드 호출 시, 파라미터의 이름을 명시하여 전달할 수 있다.
- 이렇게 하면 파라미터의 순서에 상관없이 값을 전달할 수 있으며, 가독성이 향상된다.

### C# params

- C#에서 params 키워드는 메서드에 가변 인자를 전달할 때 사용된다.
