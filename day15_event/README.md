### C# 이벤트

- 객체의 상태 변화나 특정 사건 발생 시, 이를 외부 가입자들에게 통지하는 메커니즘


- 주요 특징
	- Delegate 기반 : 이벤트는 내부적으로 델리게이트(대리자)를 사용하여 구현
	- 캡슐화 : 외부에서 직접 호출 할 수 없고, 오직 '+=', '-=' 연산자를 통해 구독과 구독 해제만 가능
	- 안정성 : 호출 전 반드시 null 체크가 필요하여, 이벤트가 구독되지 않은 경우에도 안전하게 호출 가능

- 구성 요소
	- EventHandler : 이벤트를 처리하는 메서드의 시그니처를 정의하는 델리게이트
	- sender : 이벤트를 발생시키는 객체
	- e : 이벤트에 대한 추가 정보를 담는 EventArgs 객체
