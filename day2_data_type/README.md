### 자료형 Data type

- Bool : True, False
- Byte : 0 ~ 255
- Sbyte : -128 ~ 127
- Int : -2,147,483,648 ~ 2,147,483,647
- Uint : 0 ~ 4,294,967,295
- Float : 소수점 7자리 실수 ex) 3.14f
- Double : 소수점 16자리 실수 ex) 3.14
- Char : 문자 ex) 'A', 'B', 'C'
- String : 문자열 ex) "Hello", "World"
- Object : 모든 자료형의 부모 클래스, 모든 자료형을 Object로 변환 가능
