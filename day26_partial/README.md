### C# Partial

- 클래스, 구조체, 인터페이스의 분리이다.

- Partial Type

- 가장 큰 목적은 사람이 쓴 코드와 기계가 만든 코드를 섞이지 않게 분리하는 것
- ex) Windows Form Designer에서 자동으로 생성되는 코드는 `Form1.Designer.cs`에 작성되고, 사용자가 작성하는 코드는 `Form1.cs`에 작성된다.
- 클래스가 너무 길어질 경우, 파일별로 기능을 나누어 여러 명이 동시에 작업하기 좋다.

- Partial Method

- 이런 메서드가 있을 수 있는데, 있으면 실행하고 없으면 무시해라는 개념
- 특징
	- 선언부와 구현부로 나뉘어져있다.
	- 만약 아무 곳에서도 메서드를 구현하지 않았다면 컴파일러는 메서드 호출 코드 자체를 삭제
	- 반드시 void 반환형이어야 한다.
	- 기본적으로 private
