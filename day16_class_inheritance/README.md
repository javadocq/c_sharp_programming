### C# 파생 클래스

- C#에서 부모 클래스인 기준 클래스로부터 상속하여 새로운 파생 클래스를 만들 수 있다.
- 상속을 사용하면 기준 클래스의 데이터 및 메서드들을 (public or protected) 파생 클래스에서 사용할 수 있다.
- C#에서는 파생 클래스를 정의하기 위해 클래스명 뒤에 콜론(:)과 기준 클래스명을 사용한다.
- 파생클래스가 단 하나의 기준 클래스로부터 상속되어져야 한다. 즉, 하나의 파생클래스는 2개 이상의 기준 클래스를 가질 수 없다.

### 추상 클래스

- 추상 클래스는 인스턴스화할 수 없는 클래스이다. 즉, 추상 클래스의 객체를 생성할 수 없다.
- 또한, 추상 클래스의 임의의 멤버 앞에 abstract 한정자를 사용하여 추상 멤버로 선언할 수 있다. 추상 멤버는 구현이 없는 멤버이다.
	-> 이 멤버는 꼭 파생 클래스에서 구현을 해줘야 한다는 것을 정의한다.

### as 연산자와 is 연산자

- as 연산자는 객체가 특정 타입으로 변환될 수 있는지 검사하는 데 사용된다. 변환이 가능하면 해당 타입으로 객체를 반환하고, 그렇지 않으면 null을 반환한다.
- is 연산자는 객체가 특정 타입과 호환되는지 검사하는 데 사용된다. 객체가 해당 타입과 호환되면 true를 반환하고, 그렇지 않으면 false를 반환한다.
- 두 연산자 모두 타입 검사에 사용되지만, as 연산자는 변환이 가능한 경우에만 객체를 반환하는 반면, is 연산자는 단순히 타입 호환성을 검사한다는 점에서 차이가 있다.
- 캐스팅은 명시적으로 수행되어야 하며, 변환이 실패했을 때 Exception이 발생할 수 있다. 반면, as 연산자는 변환이 실패해도 null을 반환하므로 예외 처리가 필요 없다.

```csharp
// as 연산자
MyBase a = obj as MyBase; 

// is 연산자
bool ok = obj is MyBase; //true

// Explicit Casting
MyBase b = (MyBase) obj; 
```
