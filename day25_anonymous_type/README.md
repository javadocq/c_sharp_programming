### C# Anonymous Types (익명 타입)

- 어떤 클래스를 사용하기 위해서는 일반적으로 클래스를 먼저 정의한 후 사용한다.
- 하지만, C# 3.0부터 클래스를 미리 정의하지 않고 사용할 수 있게 하는 익명타입을 지원
- new{...} 와 같은 형식을 사용하며, new 블럭 안에 속성 = 값 할당을 하고, 각 속성/값은 ,로 분리
- Anonymous Type은 읽기 전용이므로 속성값을 갱신할 수는 없다.
- C# 키워드 var는 컴파일러가 타입을 추론해서 찾아내도록 사용하기 때문에 이를 사용한다.

- 익명 타입은 LINQ를 사용할 때, 많이 사용된다.

### LINQ (Language Integrated Query)

- LINQ는 C#에서 데이터를 쿼리하는 방법을 제공하는 기능
- LINQ를 사용하면 데이터베이스, XML, 컬렉션 등 다양한 데이터 소스에 대해 일관된 방식으로 쿼리를 작성할 수 있다.
