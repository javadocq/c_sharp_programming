### C# 전처리기 지시어 (Preprocessor Directives) 정리

C# 컴파일러가 실제 소스 코드를 컴파일하기 전, 특별한 명령을 처리하도록 지시하는 구문입니다.

- 주요 특징
* **시작 기호:** 모든 지시어는 `#`으로 시작합니다.
* **끝 기호:** C# 문장이 아니므로 끝에 세미콜론(`;`)을 붙이지 않습니다.
* **범위:** 해당 파일 안에서만 효력을 가집니다. (Partial Class라도 파일이 다르면 각각 정의 필요)
* **C++과의 차이:** 별도의 전처리기가 없고 컴파일러가 직접 처리합니다.

- 주요 지시어 요약

### 1. 조건부 컴파일 (#if, #else, #elif, #endif, #define, #undef)
환경에 따라 특정 코드 블록을 포함하거나 제외할 때 사용합니다.
- `#define`: 심벌 정의
- `#undef`: 정의된 심벌 해제
- `Visual Studio Tips`: 컴파일되지 않는 영역은 코드창에서 **회색**으로 표시됩니다.

### 2. 코드 구조화 (#region, #endregion)
긴 코드를 논리적인 단위로 묶어 가독성을 높입니다. Visual Studio에서 `+/-` 버튼으로 접고 펼 수 있습니다.

### 3. 진단 및 경고 (#error, #warning)
- `#error`: 컴파일을 중단하고 에러 메시지를 출력합니다.
- `#warning`: 컴파일은 계속하되 경고 메시지를 출력합니다.

### 4. 컴파일러 제어 (#pragma)
컴파일러 고유 기능을 제어합니다.
- `#pragma warning disable`: 특정 경고 숨기기
- `#pragma warning restore`: 숨겼던 경고 다시 표시
