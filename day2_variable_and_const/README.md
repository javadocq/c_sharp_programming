### CPU의 연산 장치

- ALU : 정수만 처리 (-10, 0, 123 등)
- FPU : 부동소수점 수만 처리 
	-> 고정소수점 (fixed-point) : 소수점이 고정된 위치에 있는 수 (예: 123.45)
	-> 부동소수점 (floating-point) : 소수점이 가변적인 위치에 있는 수 (예: 1.2345e2)

- 그래서 CPU에게 데이터 종류에 따라 명령을 내려야 한다.
	-> CPU는 데이터 타입을 스스로 판단할 수 있는 능력이 없지만 컴파일러가 이를 도와준다.

### 데이터 형식

- 데이터의 유형과 크기를 지정
- 기본 데이터 형식
	- 정수 형식
	- 부동 소수형식
- 복합 데이터 형식
	- 클래스
	- 구조체
	- 인터페이스

### 변수

- 데이터를 저장하는 메모리 공간
- 코드에서 이름(식별자)을 붙여 사용
ex) int age = 30; // age라는 이름의 정수형 변수 선언 및 초기화

### 스택 

- 데이터를 쌓아 올리는 구조의 메모리
- 나중에 쌓인 데이터를 먼저 제거
- 처음에 쌓인 데이터를 나중에 제거
- 쌓인 순서의 역순으로 필요 없는 데이터를 자동으로 제거(자동메모리)

### 힙

- 자유롭게 데이터를 저장할 수 있는 메모리
- 별명 : 자유 저장소

### 값 형식

- 메모리에 값을 담는 데이터 형식
- 스택에 할당(즉, 자동으로 제거된다.)
- 기본 데이터 형식과 구조체가 여기에 해당

### 참조 형식

- 메모리에 다른 변수의 주소를 담는 데이터 형식
- 힙에 할당(가비지 콜렉터에 의해 제거된다)
- 복합 데이터 형식과 클래스 등이 여기에 해당

### 기본 데이터 형식

- C#이 제공하는 기본 데이터 형식
	- 정수형 : byte, sbyte, short, ushort, int, uint, long, ulong
	- 부동 소수점 형식 : float, double, decimal
	- 논리 형식 : bool
	- 문자열 형식 : string
	- object 형식

- 복합 데이터 형식은 기본 데이터 형식을 바탕으로 만들어진다.
	- 예시) string은 char 배열로 구성된 복합 데이터 형식이다.

### 박싱과 언박싱

- 박싱 : 값 형식을 참조 형식으로 변환해서 힙에 올리는 과정
- 언박싱 : 힙에 올라가 있는 데이터를 object에서 꺼내 값 형식으로 옮기는 과정

### 상수

- 변수와 달리 한 번 값을 할당하면 변경할 수 없는 데이터
- const 키워드를 사용하여 선언
ex) const int MAX_INT_BIT = 32; // MAX_INT_BIT라는 이름의 상수 선언 및 초기화

### 열거형식 (Enumerated Type)

- 하나의 이름 아래 묶인 상수들의 집합
- enum 키워드를 사용하여 선언
-> 예시) 
  ```cs
	enum Days { 
		Sunday, 
		Monday, 
		Tuesday, 
		Wednesday, 
		Thursday, 
		Friday, 
		Saturday 
	}; // Days라는 이름의 열거형식 선언
  ```

 ### var 키워드

- var 키워드로 선언한 변수는 컴파일러가 리터럴을 분석하여 자동으로 형식을 추론한다.
- 지역 변수에 대해서만 사용 가능
ex)
	```cs
	var age = 30; // age는 int 형식으로 추론된다.
	var name = "Alice"; // name은 string 형식으로 추론된다.
	```
