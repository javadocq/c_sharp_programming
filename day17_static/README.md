### C# static 메서드

- C#에서 static 메서드는 클래스에 속하는 메서드로, 인스턴스를 생성하지 않고도 호출할 수 있습니다. static 메서드는 클래스 이름을 통해 직접 호출할 수 있으며, 일반적으로 유틸리티 함수나 공통 기능을 제공하는 데 사용됩니다.
- static 메서드는 클래스의 상태를 변경할 수 없으며, 인스턴스 변수에 접근할 수 없습니다. 대신, static 메서드는 static 변수나 다른 static 메서드에 접근할 수 있습니다.

### C# static 속성, 필드

- static 메서드와 동일하게 인스턴스를 생성하지 않고 [클래스명.속성명]과 같이 사용하며, 다음 예와 같이 static을 앞에 붙여 정의한다.
- 클래스 내의 Non-static 필드들은 클래스 인스턴트를 생성할 때마다 메모리에 매번 새로 생성되게 되는 반면, static 필드는 프로그램 실행 후 해당 클래스가 처음으로 사용될 떄 한번 초기회되어 계속 동일한 메모리를 사용한다.

### C# static 클래스

- static 클래스는 인스턴스를 생성할 수 없는 클래스입니다. static 클래스는 모든 멤버가 static이어야 하며, 일반적으로 유틸리티 함수나 공통 기능을 제공하는 데 사용됩니다. static 클래스는 인스턴스를 생성할 수 없기 때문에, 생성자도 정의할 수 없습니다. static 클래스는 프로그램 실행 후 해당 클래스가 처음으로 사용될 때 초기화됩니다.
- static 클래스는 다른 클래스에서 상속할 수 없으며, 인터페이스를 구현할 수도 없습니다. static 클래스는 일반적으로 유틸리티 함수나 공통 기능을 제공하는 데 사용됩니다. 예를 들어, Math 클래스는 static 클래스이며, 다양한 수학 함수를 제공합니다.
- static 클래스는 프로그램 실행 후 해당 클래스가 처음으로 사용될 때 초기화됩니다. static 클래스는 다른 클래스에서 상속할 수 없으며, 인터페이스를 구현할 수도 없습니다. static 클래스는 일반적으로 유틸리티 함수나 공통 기능을 제공하는 데 사용됩니다. 예를 들어, Math 클래스는 static 클래스이며, 다양한 수학 함수를 제공합니다.
